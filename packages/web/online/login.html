Richte jetzt den zweiten Faktor ein: Scanne den Code mit einer Authenticator-App (z. B. Microsoft Authenticator, Aegis, Google Authenticator) oder tippe auf dem Handy auf den Link.

Manuell: in App öffnen oder Schlüssel eingeben:

Kein Zugriff auf die App? Gib stattdessen einen deiner Recovery-Codes ein.

Deine Recovery-Codes

Jeder Code funktioniert genau einmal, falls du keinen Zugriff auf die Authenticator-App hast. Bewahre sie sicher auf, z. B. im Passwort-Manager. Sie werden nur jetzt angezeigt.
